    About the map · methodology

    Every fish is one of the top 100 wallets holding this token. Size = USD value of the position in this token (not total net worth), tiers relative to this tank. Depth mirrors size: whales swim deep, small fish stay shallow. Positions are stable — the same wallet holds the same spot every visit.

    Data. Holder balances via Moralis, prices & volume via CoinGecko, wallet intelligence (labels, portfolios, transfers) via Arkham, X identities & trader tags via Frontrun, names via Basenames. Snapshots refresh roughly every 2 hours — the chip in the tank shows the exact capture time, and turns red if a refresh failed.

    What's filtered. Burn addresses, exchange hot wallets, bridges and known pools are excluded from the top 100 upstream. Remaining contracts and exchange-deposit wallets are hidden by default in the tables (toggle to show); ranks never renumber. The header holder count comes from Moralis and can differ slightly from Basescan.

    Change columns compare against the snapshot closest to 24h old — the header of that column states the actual window. Holders 101+ swim in the background schools; they're ambience, not data.
